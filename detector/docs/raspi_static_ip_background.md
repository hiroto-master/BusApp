# ラズパイ IPアドレス固定化ガイド

2台のラズパイで通信を行う場合、データを受け取る側（サーバー役）のIPアドレスが変わってしまうと、送る側（クライアント役）が宛先を見失ってしまいます。

これを防ぐために、IPアドレスを「固定（Static）」にする必要があります。

## 1. 原理：なぜ「固定」が必要なのか？

### 通常の仕組み (DHCP)

普段、私たちがWi-Fiに繋ぐとき、ルーター（Wi-Fiの親機）は**DHCP（Dynamic Host Configuration Protocol）**という仕組みを使っています。
- ルーター: 「空いているIPアドレスを一時的に貸してあげるよ」
- ラズパイ: 「ありがとう！じゃあ今は 192.168.0.5 を使うね」

これは「ホテルの部屋」のようなもので、チェックアウト（再起動や時間経過）すると、次は別の部屋（別のIP）に案内される可能性があります。

### 固定IP (Static IP)

サーバーとして動かす場合、これでは困ります。そこで、ラズパイ側からルーターにこう宣言させます。
- ラズパイ: 「私はずっと 192.168.0.20 を使い続けます！他の番号にはしません！」

これが「固定IP」です。これにより、クライアント（もう一台のラズパイ）は、常に同じ宛先にデータを送り続けることができます。

## 2. 設定の前に：現在の情報を調べる

固定IPを設定するには、今のネットワーク環境（ルーターの場所など）を知る必要があります。

ラズパイのターミナルで以下のコマンドを入力し、メモしてください。

```bash
nmcli device show wlan0
```

(もし nmcli が使えない古いOSの場合は ip r と cat /etc/resolv.conf を使いますが、最近はこれでOKです)

メモする項目と、複数ある場合の選び方:
- IP4.ADDRESS (IPアドレス):
  - 例: 192.168.0.15/24
  - 複数ある場合: 127.0.0.1 (自分自身) や 169.254.x.x (リンクローカル) は無視してください。192.168.x.x や 10.x.x.x 、172.16-31.x.x で始まるものを選びます。
  - 固定設定の際は、このアドレスの最後の数字だけを変えたものにします。（例: 192.168.0.20）
- IP4.GATEWAY (ゲートウェイ):
  - 例: 192.168.0.1
  - ルーターの住所です。これは絶対に間違えてはいけません。
  - 複数ある場合: 基本的に IP4.GATEWAY と書かれている行の数値を使います。もし IP4.ROUTE がたくさんあっても、GATEWAY という項目を探してください。数値はIPアドレスの先頭3ブロックと同じで、最後が .1 になっていることが多いです。
- IP4.DNS (DNSサーバー):
  - 例: 192.168.0.1
  - インターネット上の住所録です。わからなければGoogleのDNS 8.8.8.8 を使ってもOKです。

## 3. 実践：nmtui で設定する

モニターがない環境でも、ターミナル上でグラフィカルに設定できる nmtui コマンドを使います。

### 手順

- 設定画面を開く ターミナルで以下を入力します。

  ```bash
  sudo nmtui
  ```

- 接続の編集
  - 画面が出たら、キーボードの矢印キーで 「Edit a connection（接続の編集）」 を選び、Enterを押します。
  - 左側のリストから、現在接続している Wi-Fi名（SSID） を選び、右側の 「<Edit>（編集）」 を選びます。
- IPv4設定の変更
  - 「IPv4 CONFIGURATION（IPv4設定）」 という項目を探します。
  - 現在の設定が <Automatic>（自動） になっているはずです。
  - これを選択し、リストから <Manual>（手動） に変更します。
- アドレスの入力 <Show>（表示） を押して詳細を開き、以下のように入力します。
  - Addresses: 固定したいIPアドレスを入力します。
    - 必ずサブネットマスク（/24）までつけてください。
    - 入力例: 192.168.0.20/24
    - (注意: すでに他の機器が使っている番号は避けてください。20〜50あたりは空いていることが多いですが、環境によります)
  - Gateway: メモしておいたゲートウェイアドレスを入力します。
    - 入力例: 192.168.0.1
  - DNS servers: メモしておいたDNS、またはGoogleのDNSを入力します。
    - 入力例: 8.8.8.8
- 保存して終了
  - 画面一番下の <OK> まで矢印キーで移動してEnter。
  - 最初の画面に戻ったら <Back>（戻る）。
  - <Quit>（終了） を選んで終了します。
- 再起動して反映

  ```bash
  sudo reboot
  ```

## 4. 確認方法

再起動後、PCからターミナルで新しいIPアドレスに向かって接続確認（Ping）をします。

```bash
# PCのターミナルで実行
ping 192.168.0.20
```

応答が返ってくれば成功です！

これで、ラズパイAのプログラム SERVER_IP = "192.168.0.20" の設定が、永遠に有効になります。

## 5. FAQ：違うWi-Fiに繋いだ時はどうなる？

Q. 家のWi-Fiで 192.168.0.20 に固定しました。学校のWi-Fiやテザリングでも同じ 192.168.0.20 が使えますか？

A. 基本的には使えません（自動設定に戻すのが安全です）。
- 理由: Wi-Fiが変わると、ネットワークの「住所ルール（サブネット）」が変わることが多いためです。
  - 家のWi-Fi: 192.168.0.xxx
  - iPhoneテザリング: 172.20.10.xxx
  - この状態で無理やり 192.168.0.20 を使うと、インターネットに繋がりません。
- 解決策: nmtui はWi-Fiの名前（SSID）ごとに設定を覚えてくれます。
  - 家のWi-Fi: 「Manual (固定)」で 192.168.0.20 に設定。
  - テザリング: 「Automatic (自動)」のままにする。 このように設定しておけば、場所に合わせてもっともよい設定に自動で切り替わります。
- IPが変わっても接続したい場合: IPアドレスで接続するのではなく、raspberrypie.local という名前（mDNS）を使うと、IPアドレスが変わっても自動でラズパイを見つけてくれるので便利です。
