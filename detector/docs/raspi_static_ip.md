# ラズパイ IPアドレス固定化ガイド (テザリング対応版)

2台のラズパイで通信を行うため、データを受け取る側（親機：Pi B）のIPアドレスだけを固定します。

子機（Pi A）は固定する必要はありません。

## 手順1: 今のIPアドレスを調べる

まず、スマホのテザリング（または使用するWi-Fi）に接続した状態で、以下のコマンドを打ちます。

```bash
nmcli device show wlan0
```

ずらっと文字が出ますが、IP4.ADDRESS と IP4.GATEWAY の数字をメモしてください。

(例) iPhoneのテザリングの場
-

  ```bash
  ADDRESS: 172.20.10.4/28
  ```

-

  ```bash
  GATEWAY: 172.20.10.1
  ```

(例) Androidや一般Wi-Fiの場合:
-

  ```bash
  ADDRESS: 192.168.0.15/24
  ```

-

  ```bash
  GATEWAY: 192.168.0.1
  ```

## 手順2: 固定するIPを決める

メモしたIPアドレスの 「最後の数字」 だけを変えたものを固定IPにします。

他の機器と被らないよう、少し大きめの数字にするのがコツです。
- iPhoneの場合: 172.20.10.14 (iPhoneは範囲が狭いので14あたりが無難です)
- Android/Wi-Fiの場合: 192.168.0.50 (50〜100くらいが安全です)

## 手順3: 設定コマンド (nmtui)

- ターミナルで sudo nmtui と入力。
- 「Edit a connection」 を選択。
- 今使っているWi-Fi名を選択し、「Edit」。
- 「IPv4 CONFIGURATION」 を <Automatic> から <Manual> に変更。
- 「Show」 を押して入力欄を開く。
  - Addresses: 決めたIPアドレス (例: 192.168.0.50/24) ※/24などを忘れずに！
  - Gateway: メモしたGATEWAY (例: 192.168.0.1)
  -

    ```bash
    DNS servers: 8.8.8.8
    ```

- 一番下の <OK> まで進んで決定し、戻って終了。
- sudo reboot で再起動。

これで親機のIPは固定されました。このIPアドレスをメモしておいてください。
