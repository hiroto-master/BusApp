# アノテーション作業の具体的な手順ガイド

## 目的

あなたが撮影した「バスの車内の写真」を使い、「どこに人がいるか」をAIに教えるための「教師データ」を作成する。

## ステップ1: 準備 (ツールの選定とセットアップ)

なぜ専用ツールが必要か？

アノテーションは「絵を描く」作業ではなく、「座標データ（数字）」を作る作業です。手作業（マウス操作）を座標データ（例: person 0.5 0.3 0.2 0.4）に変換してくれる専用ツールが必須です。

推奨ツール: Roboflow (ロボフロウ)
- 理由: Webブラウザで動作し、インストール不要。アノテーション、データ管理、YOLO形式への変換、データ拡張（左右反転など）をすべて一括で行えるため、初心者にとって最も効率的です。
- 準備: Roboflowの公式サイト にアクセスし、無料アカウントを作成してください。

## ステップ2: プロジェクトの作成

- Roboflowにログイン
- **「Create New Project」**をクリックします。
- プロジェクト名: Bus-Passenger-Detection など、わかりやすい名前をつけます。
- Annotation Group: プロジェクト名を同じで構いません。
- Project Type: Object Detection (Bounding Box) を選びます。（これが最重要です）

## ステップ3: クラス（ラベル）の定義

アノテーションを始める前に、「何を検出するか」の名前を決めます。
- 「What classes will you label?」 と聞かれます。
- 入力欄に person と入力し、Enterを押します。
- （今回は「人」だけを検出するので、クラスは person の一つだけでOKです）
- 「Create Project」 を押します。

## ステップ4: 画像のアップロード

今日撮影してきた写真を、すべてRoboflowにアップロードします。
- 「Select Files」 または ドラッグ＆ドロップ で、バスの車内の写真をすべてアップロードしてください。

## ステップ5: アノテーション（箱付け）作業

ここがメインの作業です。アップロードした画像を1枚ずつ開き、バウンディングボックス（四角い枠）を付けていきます。
- 画像を開く: 「Unannotated (未割り当て)」の画像をクリックして、アノテーション画面を開きます。
- クラスの選択: 右側のサイドバーから、今から描くラベル person をクリックします。
- ボックスを描く:
  - 人の左上（または右上）の角でマウスをクリックします。
  - そのままマウスをドラッグ（引きずり）し、人の右下（または左下）の角でマウスを離します。
  - これで person ラベルの付いた四角い枠（バウンディングボックス）が作成されます。
- 全員に描く: 画像に映っている すべての人 に対して、このボックス作成作業を繰り返します。
- 保存して次へ: 1枚の画像が終わったら、「Save and Continue」（または Enter キー）を押して次の画像に進みます。

## ステップ6: 良いアノテーションのための「重要ルール」

AIの精度は、このルールの徹底具合で決まります。

### ルール1: 「ぴったり」囲む

ボックスは、検出したい物体（人）の全体が（見えている範囲で）ちょうど収まり、かつ背景（イスや窓）がなるべく入らないように、「タイトに（きつく）」囲んでください。
- 悪い例: ボックスが大きすぎて、背景がたくさん入っている。
- 悪い例: ボックスが小さすぎて、人の頭や足がはみ出している。
- 良い例: 人の輪郭（外縁）に、ボックスがぴったりと合っている。

### ルール2: 「重なり (Occlusion)」

人が別の人や手すりなどで部分的に隠れている場合、「推測して全体を囲む」のではなく、「実際に見えている部分だけ」を囲みます。

### ルール3: 「密集 (Dense)」

バスが混んでいて人が密集している場合、面倒でも一人ひとり、個別のボックスで囲みます。 ボックス同士が重なっても構いません。

### ルール4: 「見切れ (Truncation)」

人が写真の端で切れている（見切れている）場合も、**「フレーム内に見えている部分だけ」**を、フレームの端までぴったりと囲みます。

## ステップ7: エクスポート (YOLO形式で出力)

すべてのアノテーションが完了したら、AIの学習に使える形式でデータをダウンロードします。
- 「Generate New Version」（または「Add images to Dataset」）をクリックします。
- データ拡張 (Augmentation):
  - 「Preprocessing」（前処理）は特に不要です。
  - **「Augmentation」（データ拡張）**のステップに進みます。
  - 「Add Augmentation Step」 → 「Flip」 → 「Horizontal」（左右反転）を追加します。
  - （これで、AIが右向きの人も左向きの人も学習できるようになります）
- 「Generate」 をクリックします。
- 「Export」 をクリックします。
- Format (形式): YOLOv8 を選択します。（YOLOv5, v9, v10など、お使いのYOLOのバージョンに合わせて選んでください）
- 「Continue」 を押すと、.zip ファイルがダウンロードされます。

## 完了

お疲れ様でした。

その .zip ファイルが、YOLOのファインチューニングに使用する「教師データセット」です。

中身は、画像ファイル（.jpg）と、それに対応する座標データ（.txt）のペアになっています。
